# Open Graph Bridge Routes

## Purpose
These pages act as redirection "bridges" to external platforms (such as GitHub or Google Drive) specifically tailored for the **LinkedIn Services Marketplace**.

## Why Do They Exist?
1. **Custom Open Graph Metadata:** External platforms like GitHub and Google Drive do not allow customizing preview cards (`og:image`) with custom branding.
2. **Custom Domain Authority:** They allow serving custom 2400x1260 px preview images hosted in `/public` directly under our own domain.
3. **Smooth Client Redirection:** They render an accessible landing page with a direct fallback button and automatic JavaScript-based redirection.
