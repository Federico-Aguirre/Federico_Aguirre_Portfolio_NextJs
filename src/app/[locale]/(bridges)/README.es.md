# Rutas Puente (Open Graph Bridges)

## Propósito
Estas páginas funcionan como "puentes" de redirección hacia plataformas externas (GitHub, Google Drive) para la sección de **LinkedIn Services Marketplace**.

## ¿Por qué existen?
1. **Personalización de metadatos (Open Graph):** GitHub y Google Drive no permiten personalizar la tarjeta de vista previa (`og:image`) con nuestro diseño.
2. **Dominio propio:** Permiten servir imágenes de 2400x1260 px alojadas en `/public` bajo nuestro propio dominio.
3. **Redirección suave:** Muestran una pantalla intermedia accesible con botón directo y redirección automática por JS.
